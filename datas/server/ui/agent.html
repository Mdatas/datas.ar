DatasAgent

An agent is an AI that works step by step on a task using tools: it can find, read, write, sort and move files, open things for you, and — if you allow it — search the internet, use your camera, printer and other hardware, or run commands. It only touches the folders you tick here; anything it "deletes" goes to a trash folder you can restore from. Everything it does is shown below.
